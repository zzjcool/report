如何浏览

点击上方任意报告卡片即可在当前窗口打开完整渲染页面，支持键盘与锚点导航。

如何新增报告

将 HTML 报告文件推送至仓库根目录，索引页会自动通过 GitHub API 读取并展示。

命名建议

使用纯小写英文与下划线（如 fms_2026_report.html），URL 更干净，避免空格与中文。

索引自动维护原理

本页面通过 GET /repos/zzjcool/report/contents/ 拉取仓库根目录文件列表，筛选 .html（排除 index.html 自身），并抓取每个文件的 <title> 作为显示名。因此新增报告无需修改本页。
